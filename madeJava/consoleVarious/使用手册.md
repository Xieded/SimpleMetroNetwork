# 控制台版本使用手册说明文档

## 如何使用

---

直接编译 **main.java** 与 **consoleFiles中的所有java文件** 即可使用

## 指令说明

---

### create 指令
#### create station ["stationName"]
创建一个新的站点  
#### create railway ["railwayName"]
创建一个新的路线  

### connnect 指令 
#### connnect station [railway] [...station]
在[railway]上连接[数个站点]  

### push 指令 
#### push name [station] [newStationName]
在[station]上添加别名[newStationName](默认使用 push 方法)  
#### push station [railway] [station]
在[railway]上添加[station](默认使用 push 方法)  

### pop 指令 
#### pop name [station] 
在[station]上弹出最后一个别名  
#### pop station [railway]
在[railway]上弹出最后一个站点  

### insert 指令 
#### insert station [railway] [frontstation] [afterstation] [newstation]
在[railway]上的 [frontstation] 与 [afterstation] 中插入一个站点  

### goTo 指令 
#### goTo [startstation] [targetstation] 
（默认直接调用 printPathDetailed()）显示从[startstation]到[targetstation]的路线

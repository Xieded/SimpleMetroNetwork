# Metro Network Path Finder JS

一个基于 JavaScript 的地铁网络建模与最短路径查询工具。支持多线路、换乘惩罚、环线处理及动态站点插入，使用 **Dijkstra 算法** 在 `(站点, 当前线路)` 状态空间计算带换乘代价的最优路径。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## 特性

- **站点与线路模型**：站点可属于多条线路，线路可标记为环线。
- **网络构建**：提供 `connectStations` 批量连接站点，自动处理双向连接与线路归属。
- **换乘惩罚机制**：换乘计为额外一站代价，算法自动选择最优换乘方案。
- **路径展示**：输出路径时标注换乘站及线路切换（如 `[北京东 R2 - 上海 R1]`）。
- **站点操作**：支持在线路中插入、删除、弹出站点，自动调整连接关系。
- **完整的图算法**：基于 双向BFS 的状态空间搜索，高效且准确。
- **可靠的别名系统**：站点可拥有多个别称，随时切换当前名称，线路绑定与显示保持稳定。

## 核心类与方法

### `Station` 类

| 方法 | 描述 |
|------|------|
| `constructor(stationName)` | 创建站点 |
| `addLine(line)` | 添加所属线路 |
| `static addConnectStation(a, b)` | 建立双向相邻关系 |
| `goTo(targetStation)` | 计算最短路径，返回带 `linePath` 属性的站点数组 |
| `pushName(alias)` | 新增别名并切换当前名称 |
| `popName()` | 移除最后一个别名，恢复为首个名称 |
| `changeName(index)` | 按索引切换至指定别名 |
| `deleteName(index)` | 删除指定别名（至少保留一个） |
| `findName(name)` | 查找别名索引，不存在返回 -1 |
| `getBoundNameForLine(line)` | 获取站点在指定线路上的绑定名称（加入线路时的名称） |
| `showNextStations() / showUpStations()` | 打印当前站点的相邻站点 |

### `RailWay` 类

| 方法 | 描述 |
|------|------|
| `constructor(lineName, isLoop)` | 创建线路，可指定环线 |
| `connectStations(...stations)` | 批量连接站点并加入线路 |
| `pushStation(station)` | 将站点加入线路列表（不建立连接） |
| `popStation()` | 弹出线路末尾站点 |
| `deleteStation(station)` | 删除指定站点，自动重连相邻站 |
| `insertStation(from, insert)` | 在 `from` 站与其同线路下一站之间插入新站 |
| `showRailWayStations()` | 打印线路站点顺序及换乘信息 |
| `changeStationName(pastStation,newStationName)` | 快捷更改已绑定站点名称 |

### 辅助函数

| 函数 | 描述 |
|------|------|
| `calcPathCost(path)` | 计算路径总代价（移动 + 换乘） |
| `printPathDetailed(path, start, target)` | 格式化输出路径，标注换乘点 |

## 快速开始

```javascript
// 导入（根据环境选择一种）
import { Station, RailWay, printPathDetailed } from './MetroStation_zh.js';
// 或 const { Station, RailWay, printPathDetailed } = require('./MetroStation_zh.js');

// 创建站点
const S1 = new Station("站点A");
const S2 = new Station("站点B");
const S3 = new Station("站点C");
const S4 = new Station("站点D");

// 创建线路
const L1 = new RailWay("L1");
const L2 = new RailWay("L2");

// 构建网络
L1.connectStations(S1, S2, S3);
L2.connectStations(S4, S2);   // S2 成为换乘站

// 为站点添加别名（示例：S2 在 L1 上原称“站点B”，现别名为“换乘中心”）
S2.pushName("换乘中心");       // 当前名称变为“换乘中心”
L1.showRailWayStations();     // 仍显示 L1 的绑定名称“站点B”
L2.showRailWayStations();     // 显示“站点B”（因为加入 L2 时名称已是“站点B”）

// 查询路径
const path = S1.goTo(S4);
printPathDetailed(path, S1, S4);
```
输出示例：

```
===== L1 =====
站点A-[L1] → 站点B-[L1, L2] → 站点C-[L1], 共 3 个站
===============
===== L2 =====
站点D-[L2] → 站点B-[L1, L2], 共 2 个站
===============
路径 (从 站点A 到 站点D，经过 2 个站点，其中换乘 0 次)：
    站点A → 换乘中心
```

## 算法说明

最短路径采用 Dijkstra 算法在状态空间 (站点, 当前线路) 上搜索：

· 移动：沿当前线路走到相邻站点，代价 +1
· 换乘：在同一站点切换到另一条线路，代价 +1

该模型将换乘惩罚自然地融入边权，能够找到全局代价最小的路径。时间复杂度为 O((V·L + E·L) log (V·L))，其中 V 为站点数，L 为线路数，E 为连接边数。对于城市地铁网络规模（数百站）完全可接受。

## Q&A 常见问题

### Q1: 为什么换乘次数在输出中显示为 0？

A: 请确保使用的是最新版 goTo 方法，且 printPathDetailed 函数未对路径进行去重压缩。最新代码已保留换乘产生的连续重复站点，正确计算换乘次数。

### Q2: 如何创建环线？

A: 在实例化 RailWay 时传入第二个参数 true，或使用 setIsLoop(true)。调用 connectStations 时会自动闭合首尾。若手动添加站点，需自行调用 Station.addConnectStation(末站, 首站) 闭合。

### Q3: 删除站点后线路会断裂吗？

A: 不会。deleteStation 方法会自动将该站的上一站与下一站直接相连，保持线路连续性。若删除的是环线上的站点，环线可能会变为非环，需外部再次闭合。

### Q4: 支持同站多线换乘吗？

A: 完全支持。一个站点可以通过 addLine 加入多条线路，goTo 算法会自动考虑所有可能的换乘方案。

### Q5: 算法会考虑所有可能的路径吗？会不会太慢？

A: Dijkstra 算法保证在非负权图中找到全局最优解。对于数百个站点的网络，运行时间通常在毫秒级。若网络规模极大（如全国铁路网），可考虑使用 A* 启发式优化，但当前实现已足够应对城市地铁。

### Q6: 可以导出路径为 JSON 或其他格式吗？

A: goTo 返回的是站点数组，并附带 linePath 属性。您可以根据需要自行序列化。例如：

```javascript
const path = 黑龙江.goTo(北京西);
console.log(JSON.stringify(path.map(s => s.getStationName())));
```

### Q7: 能否设置不同线路的换乘惩罚权重？

A: 目前换乘惩罚固定为 1。如需自定义，可修改 goTo 方法中换乘部分的 newCost = cost + yourWeight。未来版本可考虑支持配置。

### Q8: 如何在浏览器中使用？

A: 本代码使用 ES6 语法，可直接在 script 标签中引入或作为模块使用。确保浏览器支持现代 JavaScript 特性即可。

### Q9: 别名系统有什么作用？会影响路径计算吗？

A: 别名系统允许一个站点在不同时期显示不同名称（例如根据实际改名），但不会影响路径计算，因为算法使用站点对象引用。线路打印和路径输出会使用站点加入线路时的绑定名称，避免因改名导致显示混乱。

### Q10: 怎样恢复站点最初的名称？

A: 站点创建时的第一个名称永远保留在别名列表的第一位。调用 changeName(0) 或执行 popName() 直到只剩下一个别名，即可恢复。

## 详细使用指南

### 1. 安装与导入

本系统使用纯 JavaScript 编写，无需额外依赖。支持 ES6 模块和 CommonJS 两种导入方式。

#### ES6 模块（推荐）

确保 `package.json` 中设置了 `"type": "module"`，或使用 `.mjs` 扩展名。

```javascript
import { Station, RailWay, printPathDetailed } from './MetroStation_zh.js';
```

#### CommonJS（Node.js）

```javascript
const { Station, RailWay, printPathDetailed } = require('./MetroStation_zh.js');
```

### 2. 创建站点与线路

#### 创建站点

```javascript
const 北京南 = new Station("北京南");
const 北京北 = new Station("北京北");
const 北京西 = new Station("北京西");
```

#### 创建线路

```javascript
const R1 = new RailWay("1号线");          // 普通线路
const R2 = new RailWay("2号线", true);    // 环线
```

### 3. 构建网络

#### 方式一：使用 connectStations 批量连接

```javascript
R1.connectStations(北京北, 北京东, 北京南, 北京西);
// 自动将站点加入线路并按顺序建立双向连接
```

#### 方式二：手动添加站点并建立连接

```javascript
R1.pushStation(北京北);
R1.pushStation(北京东);
Station.addConnectStation(北京北, 北京东);
```

### 4. 设置换乘站

只需将站点添加到多条线路即可自动成为换乘站。

```javascript
const 车公庙 = new Station("车公庙");
R1.pushStation(车公庙);
R2.pushStation(车公庙);   // 自动成为换乘站
```

### 5. 查询最短路径

调用起点站点的 goTo(targetStation) 方法。

```javascript
const path = 北京北.goTo(北京西);
printPathDetailed(path, 北京北, 北京西);
```

输出示例：

```
路径 (代价 3，其中换乘 0 次)：北京北 → 北京东 → 北京南 → 北京西
```

如果存在换乘，会显示类似：

```
路径 (代价 5，其中换乘 1 次)：黑龙江 → 北京东 → [北京东 R2→R1] → 北京中 → 北京南 → 北京西
```

### 6. 线路维护操作

#### 插入站点

```javascript
const 北京中 = new Station("北京中");
R1.insertStation(北京东, 北京中);   // 在北京东和其下一站之间插入北京中
```

#### 删除站点

```javascript
R1.deleteStation(北京南);   // 自动重连前后站点
```

#### 弹出末尾站点

```javascript
const last = R1.popStation();
console.log(`被移除的站点：${last.getStationName()}`);
```

### 7. 查看线路信息

```javascript
R1.showRailWayStations();
```

输出：

```
===== 1号线 =====
北京北-[1号线] → 北京东-[1号线, 2号线] → 北京南-[1号线] → 北京西-[1号线], 共 4 个站
===============
```

### 8. 自定义换乘惩罚权重

如需调整换乘代价，修改 goTo 方法中换乘步骤的 newCost 计算即可。

```javascript
// 原代码：换乘代价为 1
const newCost = cost + 1;

// 修改为自定义权重，例如换乘相当于 3 站
const TRANSFER_PENALTY = 3;
const newCost = cost + TRANSFER_PENALTY;
```

### 9. 获取原始路径数据

goTo 返回的数组附带 linePath 属性，可用于自定义展示或导出。

```javascript
const path = 北京北.goTo(北京西);
console.log(path);                     // 站点数组
console.log(path.linePath);            // 每个站点对应的线路
```

### 10. 完整示例

以下是一个包含换乘的完整示例：

```javascript
import { Station, RailWay, printPathDetailed } from './MetroStation_zh.js';

// 创建站点
const A = new Station("A站");
const B = new Station("B站");
const C = new Station("C站");
const D = new Station("D站");
const E = new Station("E站");

// 创建线路
const L1 = new RailWay("L1");
const L2 = new RailWay("L2");

// 连接 L1: A - B - C
L1.connectStations(A, B, C);

// 连接 L2: D - B - E
L2.connectStations(D, B, E);

// 查询路径：A 到 E
const path = A.goTo(E);
printPathDetailed(path, A, E);
```

预期输出：

```
路径 (代价 3，其中换乘 1 次)：A站 → B站 → [B站 L1→L2] → E站
```

## 注意事项

- 站点名称建议唯一，避免混淆。
- 删除站点后，环线可能被破坏，如需保持环线请手动重新闭合。
- goTo 方法在不可达时返回 null，请做好判空处理。
- 大量站点（>1000）时建议优化日志输出，避免控制台刷屏。
